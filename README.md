# 🎓 Algorithm Visualizer

> Learn algorithms through interactive, step-by-step visualizations instead of memorizing lines of code.

**🔗 Live Demo:** [algorithm-visualisation-platform-i1-vert.vercel.app](https://algorithm-visualisation-platform-i1-vert.vercel.app/)

---

## 📖 About

Algorithm Visualizer is an interactive learning platform that helps computer science students understand how algorithms work. Watch each step happen, follow the matching code as it runs, and test your understanding with challenges.

## ✨ Features

- **Step-by-step visualizations** of algorithms
- **Code synchronization** with the animation
- **Interactive controls** to play, pause, and step through
- **Challenges** to practice what you learn
- **Responsive design** for desktop and mobile

## 🛠️ Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Motion
